CONCEPT A

Split-pane terminal

LAYOUTBIGGEST WIN

Persistent 300px left rail holds nav, markets, clocks and uplink stats. Content gets the full remaining width and never reflows when you switch sections. Keys 1–6 jump sections, / focuses filter.

CONCEPT B

Density modes

READINGQUICK TO BUILD

COMPACT / NORMAL / RELAXED toggle. Compact hides summaries and images and fits ~40 headlines per screen. Choice persists in localStorage; press D to cycle.

[ OPEN DEMO B ]
CONCEPT C

Dashboard home

LAYOUTMOST IMPRESSIVE

Landing page becomes a tile grid: headlines, markets, next matches, weather, airspace, coverage bars. Click any tile to expand it to full width. Feels like a monitoring console instead of a feed.

[ OPEN DEMO C ]
CONCEPT D

Reader pane

UXNO NEW TABS

Headline list left, article right. J/K walks the wire, ESC returns to the list, source link and read-aloud live in the pane. Stacks to list→article on mobile.

[ OPEN DEMO D ]
CONCEPT E

Command palette

NAVIGATIONKEYBOARD

Ctrl+K fuzzy palette over sections, symbols, cities, leagues and actions. Replaces the whole top nav if you commit to it. History chips on the page, arrows + Enter inside the overlay.

[ OPEN DEMO E ]
CONCEPT F

80-column mode

AESTHETICEXPERIMENTAL

Hard 80-character measure, centered on black, just like a real terminal. Toggle to full width to see the same content expand. Wide tables scroll horizontally in 80-col mode.

[ OPEN DEMO F ]
Combination note: A + B stack cleanly (rail layout, density toggle in the top bar) and is the lowest-risk full revamp. C works best as a new default landing tab with the existing sections kept as drill-downs. D, E and F are independent and can bolt onto any of the above.

All demos pull live headlines from /news?limit=24 and fall back to mock data if the backend is slow.
